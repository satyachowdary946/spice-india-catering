Spice India Catering Build 14.2

Changes:
- Floating cart icon with selected-item count replaces large Review Basket bar.
- Category chips show compact numeric selected-count badges.
- Missing required event fields receive full red field treatment and inline error text.
- Admin Selected Menu has an obvious + Add Another Item tab.
- Quote email sent status is stored. WhatsApp uses an explicit Mark Sent action because a normal wa.me link cannot report delivery back to the website.
- Customers may edit their menu while New or Quoted; editing a quoted order invalidates the quote, resets it to New, and requires admin requote.
- Confirmed orders have Deposit Received and Send To Kitchen quick controls. Deposit status is saved and shown on the admin dashboard.
- Kitchen quick action opens the configured WhatsApp group; existing detailed kitchen PDF/comments workflow remains.
